Multi-store LLM orchestration agent scaling content generation to 100+ Shopify stores concurrently. Dual-provider structured output abstraction — OpenAI uses native Structured Outputs, Anthropic uses tool_use with recursive schema patching — both returning identical Pydantic objects. Includes AI-detection evaluation loop, merchant alerting, title deduplication, and semaphore-based concurrency control.
